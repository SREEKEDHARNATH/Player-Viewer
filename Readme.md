# Music Player written in C++ with sdl2 and soloud

About:-

Enter Path of file can use ctrl + c,v for copy pasting shift or ctrl backspace deletes whole use enter to start playing.

Use arrow keys to skip and control volume or gui, m for mute =, space or p for pause and resume, b for back escape for uit and gui are present too.

Use slider to go anywhere.
Support for playback speed 0.25 -> 2.

Assets are all drawn by me no ai.

Use shift or caps lock for capital letters

Hope you have a nice experience.

Gui:-
pause and resume buttons.
SKip 10 seconds forward and backward.
Volume buttons.
Slider.
Back button.
Close button.
